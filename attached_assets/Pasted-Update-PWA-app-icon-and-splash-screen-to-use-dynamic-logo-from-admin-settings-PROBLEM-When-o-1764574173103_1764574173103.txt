Update PWA app icon and splash screen to use dynamic logo from admin settings:

PROBLEM:

When opening app from Google search, home screen, or bookmark, a logo/icon appears before login page. This logo doesn't update when admin changes the app logo in settings.

CURRENT SITUATION:
- Static logo hardcoded in manifest.json
- Shows old/default logo on app launch
- Doesn't reflect admin's uploaded logo

REQUIRED FIXES:

1. FIND MANIFEST FILE:
   
   Locate: /public/manifest.json or /public/site.webmanifest
   
   Current structure likely looks like:
```json
   {
     "name": "Easy Buy Delivery",
     "short_name": "EasyBuy",
     "icons": [
       {
         "src": "/logo192.png",
         "sizes": "192x192",
         "type": "image/png"
       },
       {
         "src": "/logo512.png",
         "sizes": "512x512",
         "type": "image/png"
       }
     ],
     "start_url": "/",
     "display": "standalone",
     "theme_color": "#10b981",
     "background_color": "#ffffff"
   }
```

2. CREATE DYNAMIC MANIFEST ENDPOINT:
   
   Generate manifest.json dynamically with current logo:
```typescript
   // GET /manifest.json
   app.get('/manifest.json', async (req, res) => {
     try {
       // Fetch current logo from settings
       const settings = await db.query(
         'SELECT logo_url FROM settings WHERE id = 1'
       );
       
       const logoUrl = settings.rows[0]?.logo_url || '/default-logo.png';
       
       const manifest = {
         name: 'Easy Buy Delivery',
         short_name: 'EasyBuy',
         description: 'Online Food Delivery Services',
         start_url: '/',
         display: 'standalone',
         background_color: '#ffffff',
         theme_color: '#10b981',
         icons: [
           {
             src: logoUrl,
             sizes: '192x192',
             type: 'image/png',
             purpose: 'any maskable'
           },
           {
             src: logoUrl,
             sizes: '512x512',
             type: 'image/png',
             purpose: 'any maskable'
           }
         ]
       };
       
       res.setHeader('Content-Type', 'application/json');
       res.json(manifest);
     } catch (error) {
       console.error('Error generating manifest:', error);
       res.status(500).json({ error: 'Failed to generate manifest' });
     }
   });
```

3. UPDATE INDEX.HTML MANIFEST LINK:
   
   In /client/index.html:
```html
   <head>
     <!-- Update manifest link -->
     <link rel="manifest" href="/manifest.json">
     
     <!-- PWA meta tags -->
     <meta name="theme-color" content="#10b981">
     <meta name="apple-mobile-web-app-capable" content="yes">
     <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">

     <!-- Dynamic app icons -->

     <link rel="icon" type="image/png" href="/api/settings/logo">
   </head>
```

4. UPDATE APP ICONS IN PUBLIC FOLDER:
   
   When admin uploads new logo:
```typescript
   // After successful logo upload to Cloudinary
   async function updateAppIcons(cloudinaryUrl: string) {
     try {
       // Optionally generate different sizes
       // Or use Cloudinary transformations for different sizes
       
       const sizes = [192, 512];
       
       for (const size of sizes) {
         // Use Cloudinary to resize
         const resizedUrl = cloudinaryUrl.replace(

     }
   }
```

7. HANDLE LOGO RESIZING:
   
   Create endpoint that serves logo in different sizes:
```typescript
   // GET /api/settings/logo?size=192
   app.get('/api/settings/logo', async (req, res) => {
     try {
       const settings = await db.query('SELECT logo_url FROM settings');
       let logoUrl = settings.rows[0]?.logo_url || '/default-logo.png';
       
       // If size parameter provided and using Cloudinary
       const size = req.query.size;
       if (size && logoUrl.includes('cloudinary')) {
         logoUrl = logoUrl.replace(
           '/upload/',
           `/upload/w_${size},h_${size},c_fill/`
         );
       }
       
       // Redirect to actual logo URL
       res.redirect(logoUrl);
     } catch (error) {
       res.redirect('/default-logo.png');
     }
   });
```

8. CACHE BUSTING FOR MANIFEST:
   
   Add version to manifest to force reload:
```html
   <link rel="manifest" href="/manifest.json?v=<?= time() ?>">
```
   
   Or in React:
```typescript
   const manifestUrl = `/manifest.json?v=${Date.now()}`;
```

9. UPDATE SERVICE WORKER (if exists):
   
   If using service worker, update to cache new logo:
```javascript
   // In service-worker.js
   const CACHE_VERSION = 'v1.0.1'; // Increment when logo changes
   
   self.addEventListener('install', (event) => {
     event.waitUntil(
       caches.open(CACHE_VERSION).then((cache) => {
         return cache.addAll([
           '/',
           '/manifest.json',
           '/api/settings/logo'
         ]);
       })
     );
   });
```
